Critical Issue: JavaScript Rendering
⚠ Googlebot may not be seeing your product catalog
During the crawl, the products page returned Angular template syntax literally — including strings like {{ vm.products.pagination.totalItemCount }} Items results for {{ vm.query }}. This means the crawler received unrendered template code instead of actual product names, descriptions, and categories.
What this means in practice
Google does execute JavaScript — but with a crawl/render queue that can delay indexing of JS-rendered content by days or weeks. The "first pass" version of every product page that Googlebot indexes may contain no meaningful content. New or updated product pages may not appear in search results for an extended period.
Immediate diagnostic action (Day 1)
In Google Search Console: go to URL Inspection → enter a key product page URL → click "Test Live URL" → view the "Rendered HTML" tab. If you see Angular template strings instead of real content, SSR or prerendering is non-negotiable. Do this before any other work.

Schema Markup — Ready to Implement

Add the following JSON-LD to the homepage <head>. This is the highest-value schema addition on the site — it connects Garlock to Enpro Industries, establishes the organization's entity in Google's Knowledge Graph, and is required for Knowledge Panel eligibility.

{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Garlock",
  "alternateName": "Garlock Sealing Technologies",
  "url": "https://www.garlock.com",
  "logo": "https://www.garlock.com/[logo-path].png",
  "description": "Leaders in sealing integrity — industrial gaskets, mechanical seals, PTFE products, and sealing solutions for over 135 years.",
  "parentOrganization": {
    "@type": "Organization",
    "name": "Enpro Industries",
    "tickerSymbol": "NPO",
    "exchange": "NYSE",
    "url": "https://www.enproindustries.com"
  },
  "areaServed": "Worldwide",
  "sameAs": [
    "https://www.linkedin.com/company/garlock",
    "https://en.wikipedia.org/wiki/Garlock_Sealing_Technologies"
  ]
}

For product pages, add the following pattern to each product detail page:

{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "[Product Name, e.g. GYLON® High-Performance PTFE Gasket]",
  "description": "[Product description text from the page]",
  "brand": {
    "@type": "Brand",
    "name": "[Brand name, e.g. GYLON®]"
  },
  "manufacturer": {
    "@type": "Organization",
    "name": "Garlock"
  },
  "category": "[Category, e.g. Industrial Gaskets]"
}
