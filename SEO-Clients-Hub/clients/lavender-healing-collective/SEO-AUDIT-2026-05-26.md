# SEO Audit — Lavender Healing Collective
**Date:** 2026-05-26 | **Platform:** Squarespace | **Auditor:** Claude (SEO Strategist)

---

## Overall SEO Health Score: 34 / 100

**Justification:** The site has a powerful niche, genuine E-E-A-T potential, and a clear mission — but nearly every foundational SEO element is missing or underdeveloped. Title tags are absent across all pages, schema markup is non-existent, content is thin on key service pages, therapist credentials are buried or missing entirely, and geo-targeting is almost non-existent.

---

## Top 5 Priorities Right Now

1. Write and implement title tags on every page — currently missing site-wide
2. Add FAQPage schema to /faq — easiest structured data win
3. Build out individual therapist bio pages with full credentials — biggest E-E-A-T gap
4. Rewrite H1s on all service pages — "Therapy", "Training", "Consultation" are too generic
5. Replace Gmail contact address with branded email

### FAQPage Schema — Add to /faq

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Do you offer virtual/telehealth sessions?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Yes, all sessions are conducted via telehealth for California residents."
      }
    },
    {
      "@type": "Question",
      "name": "Do you take insurance?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "We do not bill insurance directly but can provide superbills for out-of-network reimbursement. Sliding scale rates are available."
      }
    },
    {
      "@type": "Question",
      "name": "What are your rates?",
      "acceptedAnswer": {

      }
    }
  ]
}
```

## Medium-Term Recommendations — 2–8 Weeks

### 1. Build Full Therapist Bio Pages (Highest E-E-A-T Impact)
Each of 7 clinicians needs: full name, photo, license type + number, specializations, modalities, populations served, educational background, languages, personal statement. Add Person + MedicalBusiness schema.

### 2. Add Organization Schema to Homepage

```json
{
  "@context": "https://schema.org",
  "@type": "MedicalBusiness",
  "name": "Lavender Healing Collective",
  "url": "https://www.lavenderhealingcollective.com",
  "description": "Trauma-informed, culturally responsive therapy for LGBTQIA+ BIPoC communities in California via telehealth.",
  "areaServed": "California",
  "serviceType": ["Psychotherapy", "EMDR", "Clinical Supervision", "DEI Training"],
  "knowsAbout": ["Trauma", "LGBTQIA+ affirming therapy", "BIPoC mental health"]
}
```
