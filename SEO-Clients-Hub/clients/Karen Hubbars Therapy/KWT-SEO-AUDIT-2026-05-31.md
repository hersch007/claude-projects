|---|---|---|
| Title Tags | Partial | Present on all pages but missing geographic modifiers; inconsistent format |
| Meta Descriptions | Missing | **Zero meta descriptions site-wide** — critical gap |
| H1 Tags | Issues | Homepage has no explicit H1; other pages have H1s but some are weak ("Therapy sessions:") |
| Heading Hierarchy (H2–H4) | Issues | Homepage uses H2s for section labels; Fees page uses H2s for price lines (misuse); no H2s on Approach page |
| Schema / Structured Data | None | No LocalBusiness, Therapist, FAQ, or any schema present |

| Page Speed | Moderate | Wix platform inherits some speed limitations; assess via PageSpeed Insights |

| Image Alt Text | Unknown | Not confirmed — needs manual audit in Wix editor |

**Key Technical Issues:**

1. **No meta descriptions on any page** — Google will auto-generate these from body content, often pulling irrelevant text. Write and publish custom meta descriptions for all 5 pages immediately.
2. **The /blank-page-1 URL slug** — this page is published, in the sitemap, and linked from nav as "What is IFS therapy?" but the URL gives no keyword signal whatsoever. Rename to `/ifs-therapy-resources` with a 301 redirect.
3. **No structured data** — Google cannot understand the business type, location, or services without schema. Adding LocalBusiness schema is especially impactful for therapist sites.
4. **Homepage H1 missing** — the opening question ("Do you find yourself constantly worrying...") is compelling copy but needs to be wrapped in an H1 element so crawlers understand the page's primary topic.

## 9. Conversion & User Experience Issues

- **CTAs:** Weak — the only booking CTA is "Book Appt." in the navigation (a mailto: link). There are no inline CTAs within page content to capture readers mid-scroll.
- **Contact friction:** High — booking requires composing an email from scratch. Consider adding a contact/intake form directly on the site (Wix has this built in) to reduce friction.
- **Mobile UX:** Likely adequate (Wix responsive) but needs manual testing, particularly the nav "More" dropdown.
- **Page load perception:** Moderate — Wix sites can be slow; run a PageSpeed Insights test and address any critical LCP or CLS issues.
- **Trust signals above the fold:** Partial — credentials appear in the title tag and page header, but the above-the-fold zone on the homepage leads with a question rather than Karen's name/credentials/CTA.
- **Navigation clarity:** The nav item "What is IFS therapy?" links to `/blank-page-1` — this is confusing for users and crawlers alike.

**Key Fixes:**
1. Replace the mailto "Book Appt." link with a Wix contact form or embedded scheduling widget (e.g., SimplePractice, Calendly)
2. Add a prominent CTA button ("Book a Free Consultation" or "Schedule Your First Session") in the homepage hero section
3. Fix the "What is IFS therapy?" nav item to reflect the correct URL once the slug is updated
