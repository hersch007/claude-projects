## Two-Version Workflow

Every SEO report for this client is produced in **two versions**:

| Version | Filename Pattern | Contents |
|---|---|---|
| **Client Copy** | `KWT-SEO-Report-YYYY-MM-DD.docx` | Sections 1–11 only. No Appendix. |
| **Internal Master** | `KWT-SEO-Report-YYYY-MM-DD-PartsofPractice-MASTER.docx` | Full report including Appendix (title tags, meta descriptions, schema code, additional notes). |

---

## What Goes in the Appendix (Master Only — NOT for client)

- Suggested Title Tags (ready-to-paste)
- Suggested Meta Descriptions (ready-to-paste)
- Schema Code — LocalBusiness JSON-LD
- Schema Code — FAQ JSON-LD
- Additional Notes (tools, platforms, directory recommendations)

**Rationale:** The Appendix contains the "secret sauce" — implementation-ready deliverables that Parts of Practice executes on behalf of the client. Sharing these with the client would allow self-implementation and undermine the service value.

---

## Branding & Attribution Conventions

- **Agency name in documents:** `Parts of Practice` or abbreviated `PofP`
- **Action plan owner labels:** Use `Karen` for client tasks, `PofP` for agency tasks
  - e.g., `Week 1 — Karen / PofP:` or `Week 2 — PofP:`
  - Do NOT use "Web Editor" or "SEO AI Assistant" in client-facing docs
- **Cover page "Prepared by":** `Parts of Practice`
- **Master version cover:** Add red banner: `INTERNAL MASTER VERSION — NOT FOR CLIENT DISTRIBUTION`
