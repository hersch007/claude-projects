Chat & Conversation
Claude AI responses Both
Powered by Anthropic's Claude — one of the most capable AI models available. Handles complex questions, objections, and lead qualification in a natural, human-like conversation.
Starter chip buttons Both
Three clickable buttons on the opening screen (e.g., New Customer, Existing Customer, Ask a Question) that route the conversation and reduce friction for first-time visitors.
Photo upload (vision AI) Both
Visitors can attach a photo directly in the chat window. The AI analyzes the image and responds contextually — ideal for service businesses where customers want to show a problem.
Proactive nudge trigger Both
After 45 seconds on-page or when the visitor scrolls 60% down, a small prompt appears above the chat button. Fires once per session to invite a conversation without being annoying.
Message timestamps Both
Each chat bubble shows "Just now" or "2 mins ago," updating automatically. Makes the conversation feel live and keeps the user oriented in the exchange.
Hours & seasonal logic Both
The bot automatically knows whether the business is open or closed and adjusts its response accordingly. Seasonal content (spring treatments, fall prep, etc.) is injected automatically by month.
Conversation ratings Full only
A thumbs up / thumbs down button appears below each AI response. Ratings are stored in the admin dashboard and used to identify where the bot is performing well or falling short.
Sound notification Full only
A soft audio ping plays when the AI responds, drawing the visitor's attention back to the chat if they've scrolled away or are multitasking.
Lead Capture
Lead capture flow Both
The AI collects name, email, phone, and address through natural conversation — not a form. No pop-ups, no interruptions. The transition from chat to lead happens seamlessly.
Instant email alert Both
The moment a lead is captured, a formatted HTML email fires to the team inbox with the lead's contact details and a full transcript of the conversation.
Full conversation in email Both
Every lead notification includes the complete chat so the team knows exactly what was discussed before they follow up — no context lost, no awkward cold calls.
Lead database (WP) Full only
All captured leads are stored in WordPress admin, searchable and reviewable at any time. Includes name, email, date, session ID, and the full conversation thread.
CSV export Full only
Download the complete lead list as a CSV file for import into a CRM, email platform, or reporting tool. One click from the admin dashboard.
Analytics & Insights
Admin dashboard Full only
A dedicated WordPress panel showing all chatbot activity — conversation volume, lead count, topics, peak hours, and ZIP codes — without leaving the WP backend.
Conversation logs Full only
Every conversation is stored in full with timestamps and session IDs. Review individual sessions, spot patterns, and catch issues before they affect more visitors.
Topic + ZIP analytics Full only
Conversations are automatically categorized by topic (pricing, complaints, services, etc.) and any ZIP codes mentioned are tracked — so you know what visitors ask and where they're from.
Peak hours chart Full only
A visual breakdown of when conversations happen by hour and day of week — useful for staffing decisions, scheduling follow-ups, and timing marketing campaigns.
AI business insights Full only
One click sends recent chat data to Claude, which returns a plain-English analysis of what customers are asking, what's working, and what to improve. No analyst needed.
Drop-off analysis Full only
Tracks which exchange in the conversation visitors tend to disengage, helping identify exactly where the bot loses momentum so the prompt can be refined.
Configuration & Deployment
WP settings page Both
All key settings — API key, notification email, bot name, colors, greeting, and starter buttons — managed from a single WordPress admin page. No code or FTP required.
Brand color pickers Both
Color pickers in the settings page let you set the primary and accent colors. The widget updates instantly to match any client's brand without touching the CSS.
Prompt editor in admin Both
The AI's full instruction set is editable from the WordPress settings page in the Base version. Update messaging, add services, or refine tone in minutes without touching a PHP file.
White-label / rebrand Both
The Base version is built to deploy under any business name. Every visible string, color, and label is configurable from the admin panel — one codebase, unlimited clients.
Self-update via zip upload Full only
Upload a new zip file from WordPress admin to update the plugin instantly — no deactivate, delete, or reinstall cycle. Version numbers are tracked automatically.
Rate limiting Both
Each visitor IP is limited to 30–40 messages per hour, preventing API abuse and keeping monthly Claude API costs predictable and controlled.
AI API cost (billed at cost) Both
The Anthropic API fee is tracked separately and passed through transparently on every invoice. Typical usage runs $5–15/month — no markup, no surprises.
