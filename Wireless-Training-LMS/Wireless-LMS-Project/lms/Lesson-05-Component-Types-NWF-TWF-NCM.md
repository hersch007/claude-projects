## Overview

Once your Project Information Form (PIF) has been approved and your invoice has been issued, AMP activates the components required for your project. These components are not optional forms — they are the structured, regulated data collection system that drives every review, approval, and inspection decision in AMP.

Each component collects a specific category of information. Together, they build the complete picture of what is being proposed, where it is being built, what structure it will use, and whether it is safe, legal, and compliant.

> **Key Point:** The PIF tells AMP *what kind* of project this is. The components collect *everything else* — justification, structural data, legal documents, safety certifications, and construction details.

---

## The Four Components of AMP

AMP uses four core components, each serving a distinct role in the application process:

| Component | Full Name | When Required |
|-----------|-----------|---------------|
| **ATF** | Add Tower Form | When adding a new tower site not yet in the WTS database |
| **NWF** | New Wireless Facility | New Tower projects only |
| **TWF** | Tower/Wireless Facility Registration | When tower data is not current in the WTS database |
| **NCM** | New Colocation/Modification | **ALL project types — no exceptions** |

## Component 1: ATF — Add Tower Form

### What It Is
The Add Tower Form registers a new tower site in the WTS database. It is the foundational record for a physical tower location and all its associated technical data.

### When It Is Required
The ATF must be completed **any time an Agent adds a tower site that does not already exist in the WTS database.** If the tower is already registered and its information is current, the ATF is not needed again.

### What It Collects
The ATF gathers comprehensive site and tower identification data, including:

**Site Identification**
- Tower Owner Site ID and Site Name
- Tower Owner name, phone, and email
- Carrier Name, Carrier Site Name, Carrier Site Number
- Site address: street, city, county, state, zip code
- E911 compliance status

**Tower Physical Data**
- Tower type (self-supporting, guyed, stealth, etc.)
- Tower height and setback distance
- Number of current colocations
- Number of antennas and Remote Radio Heads (RRH)
- Heights of antennas and RRH

**Legal and Agreement Data**
- Land Use Agreement type and dates (start, term, renewals)
- Land Use Agreement/Deed document upload
- Tower access codes and private access information

**Engineering and Safety Records**
- Tower inspection date and expiration
- Tower inspection report (uploaded document)
- Soils study date, company, Professional Engineer name, registration number and state
- Soils study report (uploaded document)
- Tower insurance document and expiration date
- ANSI standard used in the structural report

**Location Data**
- Latitude and Longitude in both Decimal Degrees and Degrees/Minutes/Seconds (DMS)

### Why It Matters
The ATF is the permanent record for a tower site. Every future project that uses this tower will reference the ATF data. Inaccurate tower information here — wrong height, wrong location, outdated inspection data — will affect every subsequent application filed on that site.

## Component 2: NWF — New Wireless Facility

### What It Is
The New Wireless Facility component provides the regulatory justification for building a brand-new tower structure. It answers the fundamental question: *Why is a new tower necessary here?*

### When It Is Required
The NWF is required **only for New Tower project types.** If an application is a Colocation, Modification, or any Eligible Facility type, the NWF is not needed because the tower structure already exists.

### What It Collects

**Justification Documents**
- A PDF document explaining the justification for the new tower
- A PDF documenting efforts to utilize *existing* structures before proposing a new one — this is a regulatory requirement in most ordinances; applicants must demonstrate they explored alternatives
- A CSV file listing all property owners within 1,500 feet of the proposed site property lines *(The Jurisdiction uses this list to provide required public notifications)*

**Facility Details**
- Type of facility planned (new tower, DAS system, temporary, etc.)
- Total number of future users the tower is designed to support
- A PDF document describing the tower's capacity to support future collocators

**Legal Identity**
- Applicant's legal name (the FCC Licensed Carrier submitting the application)

### Why It Matters
Local governments have the authority to require justification before approving any new tower structure. The NWF is how an Agent proves to the Jurisdiction that a new tower is both necessary and that all reasonable alternatives have been considered. A weak or incomplete NWF is one of the most common reasons new tower applications are sent back for revision.

## Component 3: TWF — Tower/Wireless Facility Registration

### What It Is
The Tower/Wireless Facility Registration component captures the structural and ownership details of the tower that will support the wireless facility. It is the tower's official registration record.

### When It Is Required
The TWF is required **when the tower's information is not already current in the WTS database.** If the tower was previously registered via an ATF and no significant changes have occurred, the TWF may not need to be completed again. If the tower is already defined and current, AMP does not require a new TWF.

### What It Collects

**Tower and Site Identity**
- Tower Owner, Site ID, Site Address and City
- Carrier Name, County, State, Zipcode
- Land Use Agreement type and supporting deed document

**Property Owner Information**
- Property Owner name, address, phone, email
- Emergency contact name and phone

**Tower Physical Characteristics**
- Tower Type and Tower Height
- Company performing tower inspection
- ANSI standard used for the inspection report
- Tower Inspection Date and Expiration Date
- Tower Inspection Report (uploaded document)
- Tower support type

**Soils Engineering Data**
- Date soils study was completed
- Company performing the certified soils study
- Soils Study Professional Engineer (name, registration number, registered state)
- Soils Study Report (uploaded document)

### Why It Matters
The TWF ensures the physical tower structure is properly documented before any new equipment is added to it. A jurisdiction cannot responsibly approve new equipment on a tower without knowing the tower type, its inspection history, and whether a current soils study exists. This is a direct health, safety, and welfare responsibility.

## Component 4: NCM — New Colocation/Modification

### What It Is
The New Colocation/Modification component is the **most important component in AMP.** It is the only component required for *every single project type* — no exceptions. The NCM collects the detailed engineering, legal, and construction data that proves the proposed work is structurally safe and legally compliant.

> **Critical Rule:** If a project is in AMP, it has an NCM. Every project. Always.

### When It Is Required
**All project types.** New Tower, Colocation, Modification, Eligible Facility Colocation, Eligible Facility Modification, Small Wireless Facility — every single one requires a completed and approved NCM.

### What It Collects — Six Sections

#### Section 1: Project Modifiers
Auto-populated from the PIF. Confirms: Agent ID, Project ID, Colocation/Modification ID, Project Name, Licensed Carrier's name, and Project Type.

> *This information is automatically uploaded when the Project is created and approved — the Agent does not have to re-enter it.*

#### Section 2: Certified Site Plan Engineer
- Name, email, and phone of the engineer responsible for the site plan
- **Must be a Professional Engineer (PE) licensed in the state where the project is located**
- All certified documents must be stamped and sealed by this licensed PE

#### Section 3: Site Plan Information
- Total number of new antennas (all sectors)
- Number of new Remote Radio Heads (RRH), Remote Radio Units (RRU), and similar devices
- Centerline heights (in feet) of new antennas
- Centerline heights (in feet) of new RRH/RRU equipment
- **Setback** — the shortest distance in feet to any adjacent property or public rights-of-way; must be equal to or greater than the tower height plus 10%
- Upload of the Certified Site Plan (PDF) — must address: location, size and height of all structures; landscaping, fencing; tower and antenna description; grounding; parking; signage; and how the base and structures will be screened from public view

#### Section 4: Structural Analysis Information
- Name, email, and phone of the Certified Structural Analysis Engineer (PE licensed in state)
- Upload of the Certified Structural Analysis (PDF) — must be completed per ANSI/TIA-222 G/H or later, as applicable to the state
- **Maximum % Loading on the Tower** — taken directly from the structural analysis report
  - ⚠️ **If loading exceeds 100%, the Agent will not be permitted to submit the NCM.** The tower must be proven structurally safe before any application can proceed.

#### Section 5: Legal Information
- FCC Carrier License (PDF) — for the carrier, not the tower
- FCC Compliance Document (PDF) — confirms the site complies with FCC RF emissions requirements
- Performance Bond (PDF) — must equal the value specified in the Ordinance; must remain valid as long as the site is active
- Certificate of Insurance (PDF) — must name the jurisdiction, its officers, employees, agents, and consultants as additional named insureds
- Insurance Expiration Date — must be kept current; Agents are responsible for keeping the Jurisdiction updated

#### Section 6: Construction Information
- Estimated construction start date
- Estimated construction completion date
- Contractor name — must be licensed to perform work within the jurisdiction *(may not be known at time of submission; this becomes a permit condition)*
- Copy of Contractor's Business License (PDF)

> **Visual:** [INSERT IMAGE: NCM form showing Section 4 — Structural Analysis — with the Maximum % Loading field highlighted]
> *Caption: The Maximum % Loading field in Section 4 is a hard stop. If the value exceeds 100%, AMP will not allow submission. This is a non-negotiable structural safety requirement.*

### Why It Matters
The NCM is the structural and legal core of every application. It is where the Jurisdiction and WTS Analysts confirm:
- That the proposed work is structurally safe for the existing tower
- That certified engineers have reviewed and stamped all plans
- That the carrier has proper insurance and bonding in place
- That the site complies with FCC regulations
- That a licensed contractor will perform the work

Every approval decision made in AMP ultimately rests on the data in the NCM. An incomplete or inaccurate NCM is the single most common cause of revision requests and approval delays.

## How Components Connect to the PIF — and the Invoice

Here is the critical flow to understand:

1. **PIF is approved** → AMP identifies which components are required
2. **Invoice is issued** → Agent receives the invoice by email
3. **Agent begins filling out components** → Available immediately after PIF approval *(Platform Update, May 2026)*
4. **Agent saves work continuously** — SAVE after every entry and every upload
5. **Payment is confirmed** → Submission unlocks
6. **Agent submits completed components** → Analyst/Jurisdiction review begins

> **Important:** Agents can fill out and save all components before payment clears. This eliminates wait time during payment processing. However, **no component can be submitted for review until payment is confirmed.**

> **SAVE Reminder:** After EVERY entry and EVERY upload, click SAVE. Do not depend on auto-save. Do not navigate away without saving. Lost data cannot be recovered.

## Common Mistakes with Components

**Mistake 1 — Submitting the wrong project type in the PIF**
The wrong project type triggers the wrong components. A Modification filed as a New Tower will generate NWF and TWF requirements that don't belong. This causes delays and potentially incorrect fees. Fix the PIF first — everything else follows from it.

**Mistake 2 — Uploading uncertified documents to the NCM**
All structural analyses and site plans must be stamped and signed by a PE licensed in the state. Uploading unsigned or uncertified PDFs is one of the most common revision triggers.

**Mistake 3 — Exceeding 100% tower loading**
If the structural analysis shows the tower will exceed 100% loading with the proposed equipment, the project cannot proceed as submitted. The solution is a structural upgrade, equipment reconfiguration, or a different tower — not a workaround in the form.

**Mistake 4 — Forgetting to update insurance**
Insurance expiration dates must be maintained throughout the life of the project. An expired insurance certificate can stall an inspection or final approval. Agents are responsible for proactively updating the Jurisdiction when insurance is renewed.

**Mistake 5 — Assuming the NCM is optional for simple projects**
There is no project type in AMP that does not require a completed NCM. Even an Application Update — the simplest project type — requires NCM completion.

## Key Takeaways

- AMP uses four components: **ATF, NWF, TWF, and NCM** — each serving a distinct purpose
- The **NCM is the only component required for every project type** — it collects structural, legal, and construction data
- The **NWF is only required for New Tower projects** — it provides the justification for new construction
- The **TWF captures tower registration data** — only required if the tower is not already current in the WTS database
- The **ATF registers new tower sites** in the WTS database — required when the site doesn't yet exist in the system
- **Components are triggered by the PIF** — the correct project type in the PIF is critical
- After PIF approval, **agents can begin filling out components immediately** — but cannot submit until payment is confirmed
- **SAVE constantly.** Every entry, every upload. Data is not auto-recovered.

## Checkpoint Question

**Scenario:** An Agent is working on a Colocation project on an existing tower that is already registered and current in the WTS database. The PIF has been approved and the invoice has been issued. The Agent contacts you and says: *"I can only see one component in my project. Is something wrong?"*

What is the correct response?

**A)** Something is wrong — all four components should always be visible. The Agent should contact technical support.

**B)** This is correct. A Colocation on a tower already in the WTS database only requires the NCM. One component is expected.

**C)** The Agent needs to complete the ATF first before the other components will appear.

**D)** The invoice must be paid before the correct components will display.

---

**✓ Correct Answer: B** — A Colocation project on a tower that is already registered and current in the WTS database requires only the NCM. The ATF is not needed (tower already in DB), the NWF is not needed (not a New Tower), and the TWF is not needed (tower data is current). One component — the NCM — is entirely correct. If the Agent were unsure about the tower's status in the database, they should confirm with their WTS Analyst.
