# Characters

Character profiles, relationship maps, and arc tracking for all named characters.

## File Structure

```
characters/
  protagonist-[name].md     ← lead characters get their own file
  love-interest-[name].md
  supporting-cast.md        ← secondary characters in one file
  relationship-map.md       ← how characters connect
  arc-tracker.md            ← emotional arc per character across chapters
```

## Character Roster

| Name | Role | File |
|---|---|---|
| | Protagonist | `protagonist-[name].md` |
| | Love Interest | `love-interest-[name].md` |
| | Best Friend | `supporting-cast.md` |
| | Antagonist | `supporting-cast.md` |

## What Goes in a Character Profile

- Full name, nickname, age
- Physical description (canonical — matches what's in the text)
- Occupation and backstory
- Core wound / internal conflict
- External goal / internal goal
- Voice notes (speech patterns, vocabulary, what they'd never say)
- Key relationships
- Arc summary (where they start vs. where they end)
- Fun facts / details for authenticity
