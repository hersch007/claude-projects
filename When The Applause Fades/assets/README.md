# Assets

All visual and brand assets for "When the Applause Fades."

## Folder Structure

```
assets/
  cover/          ← cover art files in all formats
  author-photos/  ← headshots (multiple crops/resolutions)
  graphics/       ← social media graphics, banners, quote cards
  branding/       ← fonts, color palette, logo if applicable
  mockups/        ← 3D book mockup renders
```

## Cover Asset Requirements

| Format | Dimensions | Use |
|---|---|---|
| eBook cover (JPG) | 2,560 × 1,600 px | KDP, retailers |
| eBook cover (PNG) | 2,560 × 1,600 px | Website, high-res social |
| Print cover (PDF) | Spine + bleeds, per KDP calculator | KDP Print |
| Thumbnail | 200 × 300 px | Blog headers, small displays |
| Square crop | 1,080 × 1,080 px | Instagram feed |
| Story crop | 1,080 × 1,920 px | Instagram/TikTok stories |

## Author Photo Requirements

- Minimum 300 dpi for print
- At least one square crop (for social profiles)
- One landscape crop (for website header / banner)
- Neutral background version for press kit
