# Lyrics

Original song lyrics written for or featured in "When the Applause Fades."

## Why This Folder Matters

If the story features a musician, songwriter, or performer, the songs they write/perform are part of the story's world. Original lyrics need to be:
- Consistent with the character's voice and genre
- Tracked for continuity (which song appears in which scene)
- Separate from the manuscript so they can be polished independently
- Potentially used in marketing (teasers, social content)

## Notes on Using Real Songs

If referencing real, existing songs (not original lyrics):
- List them here with artist and year
- Check licensing/fair use before including lyrics in the text — song lyrics are aggressively copyrighted
- Titles and general references are generally fine; quoting lyrics is not
