# Manuscript

This folder holds all active working drafts.

## File Naming Convention

```
ch01_draft1.docx
ch01_draft2.docx
ch02_draft1.docx
full-manuscript_draft1.docx
```

Use `draft1`, `draft2`, etc. to version chapters. Never overwrite — always save a new draft number.

## Workflow

1. Write chapter here as `chXX_draft1.docx`
2. When a chapter is approved/locked, copy it to `approved-manuscript/`
3. Archive old drafts in `archive/` rather than deleting them
