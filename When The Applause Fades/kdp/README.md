## Upload Checklist

### Before Upload
- [ ] Manuscript formatted for eBook (Vellum, Atticus, or Word)
- [ ] Manuscript formatted for print (if applicable)
- [ ] Cover (eBook): 2,560 × 1,600 px, JPG, under 50 MB
- [ ] Cover (print): full wrap with spine, PDF
- [ ] ISBN assigned (or use KDP's free ISBN — note limitations)
- [ ] Metadata finalized (see `metadata.md`)
- [ ] Copyright page drafted
- [ ] Dedication page drafted
- [ ] Author bio for back matter finalized
- [ ] CIP data / Library of Congress not required for self-pub but optional

### During Upload
- [ ] Title and subtitle entered
- [ ] Author name as it will appear on cover
- [ ] Series name and number (if applicable)
- [ ] Description (blurb) — HTML formatting supported
- [ ] Keywords (7) — see metadata.md
- [ ] Categories (2 on KDP; 10 with expanded categories tool)
- [ ] Age/grade range
- [ ] Pre-order date set (if applicable)
- [ ] Pricing entered

### After Upload
- [ ] Preview reviewed on Kindle Previewer
- [ ] Print proof ordered and reviewed (if applicable)
- [ ] All links in back matter tested
- [ ] Goodreads listing created/claimed
- [ ] BookBub profile updated
