# Archive

Old drafts, cut scenes, retired outlines, and anything removed from the active project.

**Never delete from the archive.** If something is here, it was once in the manuscript and may be useful again.

## What Belongs Here

- Cut scenes or chapters (label clearly with why they were cut)
- Earlier draft versions superseded by approved versions
- Retired outlines or beat sheets
- Old blurb versions
- Anything you're "not sure about yet" and want to set aside rather than delete

## File Naming Convention

```
ARCHIVE_[original-filename]_[reason]_[date].docx
ARCHIVE_ch03_draft1_cut-scene-backstory_2026-03.docx
ARCHIVE_full-manuscript_v1_pre-edit_2026-05.docx
```

## Retrieving Archived Content

If you want to bring something back:
1. Copy (do not move) the file back to its original location
2. Rename it with a new draft number
3. Note the retrieval in the archive index
