# Editorial Feedback

All external feedback on the manuscript lives here — editors, critique partners, sensitivity readers.

**Do not delete feedback files**, even after revisions are complete. They form a useful record of the book's development.

## File Naming Convention

```
[round]_[source]_[date].md
ed1_developmental_2026-01.md
ed2_line-edit_2026-04.md
cp_jane-doe_2026-02.md
sensitivity_[focus]_2026-03.md
```

## Revision Response Process

For each round of feedback:
1. Read all notes before making any changes
2. Create a response document (`response_[round].md`) noting what you're acting on and what you're declining
3. Make revisions in `manuscript/`
4. Move revised chapters to `approved-manuscript/` when done
