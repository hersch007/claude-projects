# Start Performance Platform

A modular WordPress-based business automation platform.

## Project Folders

- `/docs` — Claude prompts, planning docs, architecture notes
- `/current-plugins` — existing plugin zips or source folders
- `/screenshots` — screenshots of existing dashboards, forms, and UI ideas
- `/reference-files` — supporting files, CSS, JS, HubSpot notes, API docs, etc.

## Start Here

Open `/docs/CLAUDE_START_PROMPT.md` and paste it into Claude Code.

Then upload or place the existing working files into `/current-plugins` before asking Claude to inspect the codebase.
